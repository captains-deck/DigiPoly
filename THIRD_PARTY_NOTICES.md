# Third-party notices and asset provenance

The root [MIT licence](LICENSE) applies to DigiPoly's original source and included project assets. It does not replace third-party licences.

## OpenCV

`vendor/opencv.js` is the unmodified JavaScript/WebAssembly distribution from `@techstark/opencv-js@4.11.0-release.1`. Its Apache-2.0 licence is retained in [vendor/LICENSE-OpenCV.txt](vendor/LICENSE-OpenCV.txt). Package source, upstream link and verified archive integrity are recorded in [vendor/README.md](vendor/README.md).

Retain these notices when distributing the website or desktop app. The website build and desktop packaging scripts include the vendored licence.

## Electron and build dependencies

Electron is supplied through the official `electron` npm package. Packaged apps retain Electron's own licence and the Chromium/third-party notices distributed with it. These components have their own terms; they are not relicensed by DigiPoly.

Development dependencies and their resolved versions are recorded in `package-lock.json`. The desktop staging directory contains the application allowlist, not the development `node_modules` tree. Keep the upstream licence files in any redistributed runtime.

## Project artwork

- `assets/brand/`: project marker geometry and generated SVGs. Portal v4 is an editable-vector refinement of the linked DigiPoly logo; `portal-logo.png` is rendered from that geometry and `digipoly.icns` is generated from it, with the small sizes taken from the separate favicon. `portal-logo-v3.png` keeps the supplied v3 raster. DP-001 uses the v4 design; DP-002 turns the inner corner links. V3 and v2 detection remain available for existing prints.
- `assets/artwork/`: fictional demonstration brands/products, generated by `scripts/campaign-assets.mjs`.
- `assets/backgrounds/bedroom-stream.png`: AI-generated fictional creator bedroom. Its provenance and generation prompt are recorded in [assets/backgrounds/README.md](assets/backgrounds/README.md).
- `references/`: local design-reference images, excluded from source publication and application builds.

User-uploaded media belongs to its respective owner and is not part of this repository's licence. Uploads and desktop account/cache files must not be bundled in source or release archives.

## GhostMarker

`vendor/ghostmarker/` is a versioned snapshot of the separate GhostMarker project, licensed under its retained [MIT licence](vendor/ghostmarker/LICENSE). Source hashes and version are in `vendor/ghostmarker/snapshot.json`. It contains an original experimental DCT codec; no StegaStamp or TrustMark model weights or source are bundled. The existing OpenCV runtime is shared.
